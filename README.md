Futuristic Apple-Inspired Web Experience

A production-grade, futuristic technology showcase and e-commerce experience built entirely with **Vanilla HTML5, CSS3, and modern ES6+ JavaScript**. Designed with the precision, minimalism, and luxury of Apple's flagship product launches.

https://aventra-iota.vercel.app/




## 🌟 Overview

**AURA** is a cinematic, interactive web experience showcasing next-generation photonic computing devices:
- **Aura One Pro**: Flagship photonic-silicon superphone crafted in sculpted Grade 5 Titanium.
- **Aura Studio M5**: Zero-thermal desktop workstation with quantum neural engine.
- **Aura Neural Glass**: Spatial photonic eye-wear with true-depth holographic optics.
- **Aura Chronos**: Atomic-precision timekeeper with continuous biometric telemetry.
- **Aura Pods Ultra**: Lossless spatial acoustic soundstage with active acoustic isolation.

## 🚀 Key Features

### 1. Liquid Glass & Titanium Design System
- Multi-layered backdrop blur with refined light rim highlights and inner reflections.
- Ultra-subtle procedural grain texture for tactile depth.
- Custom Apple SF Pro typography hierarchy with fluid display clamps.
- Restrained graphite, silver, deep obsidian, and titanium color palette.

### 2. Interactive Flagship Configurator
- Real-time finish switcher (Natural Titanium, Space Obsidian, Cosmic Silver, Aurora Blue) with dynamic high-resolution image rendering.
- Interactive multi-angle thumbnail gallery.
- Live storage and connectivity tier selection with instant price recalculation.
- Quantity adjustment, Add to Bag, Buy Now, and Wishlist toggling.
- Persistent state via browser `localStorage`.

### 3. Dynamic Product Showcase
- Category tab switcher with smooth transitions across the product line.
- Rich product specs, pricing, and direct action triggers.

### 4. Interactive Letter-by-Letter CTA Buttons
- Pure CSS and JavaScript character-splitting text morph animations (`Explore` → `Exploring`, `Reserve` → `Reserving`).
- No external animation libraries (zero GSAP / Framer Motion dependency).

### 5. Interactive Benchmark & Spec Comparators
- Live interactive performance comparisons (Photonic M5 vs M4 Pro vs Industry Standard).
- Filterable technical specification sheets.

### 6. Full-Text Search Overlay
- Instant modal search with keyboard shortcuts (`Cmd+K` / `Ctrl+K` / `/`).
- Live filtering across products, features, and technical specifications.
- Full keyboard navigation (Arrow Up/Down, Enter, Escape).

### 7. Persistent Cart Drawer & Demo Checkout
- Slide-over liquid glass bag with item management and real-time total calculations.
- Complete multi-step checkout demonstration modal with shipping calculator, payment simulator (Apple Pay / Credit Card), and order confirmation generator.

### 8. Dedicated FAQ Page (`faq.html`)
- Searchable knowledge base with category filters (Products, Orders, Warranty, Privacy, Ecosystem).
- Accessible accordion with smooth plus-to-X rotating indicators.
- Valid `FAQPage` JSON-LD Schema structured data for search engine rich snippets.

### 9. Production-Grade SEO & Accessibility
- Complete Open Graph, Twitter Cards, Canonical tags, Theme colors, and Structured Data (`Organization`, `Product`, `WebSite`, `FAQPage`).
- ARIA live regions, semantic elements, focus traps, and `@media (prefers-reduced-motion)` support.
